# Linux `cp` 命令用法文档

**适用版本**：GNU coreutils（主流 Linux 发行版默认采用）

## 一、命令概述

`cp` 用于在 Linux 中复制文件或目录。复制得到的副本与原始文件完全独立，对副本的修改不会影响原文件。`cp` 支持将一个文件复制为另一个文件，也支持将任意多个源文件复制到一个目标目录中。

**默认行为**：`cp` 默认**不复制目录**，必须显式使用 `-r`、`-R` 或 `-a` 才能递归复制目录内容。

## 二、命令语法

`cp` 有三种基本调用形式：

```bash
cp [选项]... [-T] 来源 目标
cp [选项]... 来源... 目录
cp [选项]... -t 目录 来源...
```

| 形式               | 含义                               |
| ---------------- | -------------------------------- |
| `cp 来源 目标`       | 将单个文件复制为 `目标`（可以是文件名，也可以是已存在的目录） |
| `cp 来源... 目录`    | 将多个源文件复制到目标目录中，各自保留原文件名          |
| `cp -t 目录 来源...` | 显式指定目标目录，适用于源文件数量较多或目标目录名有歧义的场景  |

## 三、常用选项分类说明

### 3.1 递归与目录操作

| 选项                          | 含义                                                                |
| --------------------------- | ----------------------------------------------------------------- |
| `-r` / `-R` / `--recursive` | **递归复制**目录及其全部内容（子目录、文件等）                                         |
| `-a` / `--archive`          | **归档复制**，等价于 `-dR --preserve=all`，保留符号链接、权限、时间戳、所有权等尽可能多的属性，常用于备份 |

> `-a` 是“复制目录并保留一切属性”的常用首选，`-r` 则只负责递归，不额外保留属性。

### 3.2 覆盖控制（是否覆盖已有文件）

| 选项                     | 含义                                             |
| ---------------------- | ---------------------------------------------- |
| `-i` / `--interactive` | **覆盖前询问**，防止误覆盖                                |
| `-n` / `--no-clobber`  | **不覆盖**已有文件，直接跳过，不提示                           |
| `-f` / `--force`       | 当目标文件无法打开（如权限不足）时，**删除后重试**                    |
| `-u` / `--update`      | **仅当源文件比目标文件新，或目标文件不存在时才复制**                   |
| `--remove-destination` | 在复制前**先删除**已存在的目标文件（与 `-f` 不同：`-f` 仅在无法打开时才删除） |

> `-i` 与 `-n` 互斥，后出现的选项覆盖先出现的；`-n` 与 `-b` 也互斥。

### 3.3 属性保留

| 选项                  | 含义                                                                              |
| ------------------- | ------------------------------------------------------------------------------- |
| `-p`                | 等价于 `--preserve=mode,ownership,timestamps`，保留权限、所有者、时间戳                         |
| `--preserve[=列表]`   | 按需保留属性，列表可用逗号分隔：`mode`、`ownership`、`timestamps`、`links`、`xattr`、`context`、`all` |
| `--no-preserve=列表`  | 不保留指定属性                                                                         |
| `--attributes-only` | **只复制属性，不复制文件内容**                                                               |

### 3.4 符号链接处理

| 选项                        | 含义                                                       |
| ------------------------- | -------------------------------------------------------- |
| `-P` / `--no-dereference` | **不跟随**符号链接，复制链接本身（`-d` 隐含此行为）                           |
| `-L` / `--dereference`    | **总是跟随**符号链接，复制链接指向的实际文件                                 |
| `-H`                      | 仅跟随命令行中显式给出的源符号链接                                        |
| `-d`                      | 等价于 `--no-dereference --preserve=links`，复制符号链接本身并保留硬链接关系 |
| `-l` / `--link`           | 不进行复制，而是创建**硬链接**（仅对非目录有效）                               |
| `-s` / `--symbolic-link`  | 不进行复制，而是创建**符号链接**                                       |

> 当同时指定多个链接相关选项时，**最后一个生效**。

### 3.5 备份与后缀

| 选项                      | 含义                                  |
| ----------------------- | ----------------------------------- |
| `-b`                    | 为每个将要被覆盖的目标文件**创建备份**（不接受参数）        |
| `--backup[=方式]`         | 创建备份，可指定方式（如 `simple`、`numbered` 等） |
| `-S 后缀` / `--suffix=后缀` | 自定义备份文件后缀（默认 `~`）                   |

### 3.6 输出与辅助

| 选项                 | 含义                  |
| ------------------ | ------------------- |
| `-v` / `--verbose` | 显示复制过程的详细信息         |
| `--debug`          | 输出更详细的调试信息（隐含 `-v`） |
| `--help`           | 显示帮助信息并退出           |
| `--version`        | 显示版本信息并退出           |

## 四、典型用法示例

### 4.1 复制单个文件

```bash
cp report.txt report_backup.txt
```

将 `report.txt` 复制为 `report_backup.txt`。若 `report_backup.txt` 已存在，将被**直接覆盖**（默认行为，无提示）。

### 4.2 复制文件到目录

```bash
cp report.txt /home/user/documents/
```

将 `report.txt` 复制到 `/home/user/documents/` 目录下，文件名保持不变。

### 4.3 复制多个文件到目录

```bash
cp file1.txt file2.txt file3.txt /home/user/backup/
```

三个文件全部复制到目标目录中，各自保留原文件名。

### 4.4 递归复制目录

```bash
cp -r project/ project_copy/
```

将整个 `project` 目录（含所有子目录和文件）复制为 `project_copy`。

### 4.5 归档复制（保留全部属性，适合备份）

```bash
cp -a /var/www/ /backup/www-$(date +%F)/
```

以归档模式复制站点目录，保留符号链接、权限、时间戳、所有权等，是日常备份和迁移的常用方式。

### 4.6 复制前询问（防止误覆盖）

```bash
cp -i important.txt /mnt/backup/important.txt
```

若目标文件已存在，终端会提示是否覆盖，输入 `y` 确认，`n` 取消。

### 4.7 仅复制更新的文件

```bash
cp -u *.log /archive/logs/
```

只复制那些比目标目录中同名文件**更新**的日志文件，适合增量同步场景。

### 4.8 复制并保留权限与时间戳

```bash
cp -p script.sh /usr/local/bin/
```

复制后，目标文件的权限、所有者、时间戳与源文件一致，不会变成“刚创建”的状态。

### 4.9 创建硬链接代替复制

```bash
cp -l largefile.img largefile_link.img
```

不占用额外磁盘空间，两个文件名指向同一份数据。注意：仅适用于同一文件系统内的非目录文件。

### 4.10 覆盖前自动备份

```bash
cp -b config.conf /etc/app/config.conf
```

若 `/etc/app/config.conf` 已存在，会先生成 `config.conf~` 备份，再执行覆盖。

### 4.11 显示复制详情

```bash
cp -v -r docs/ docs_backup/
```

输出类似 `'docs/a.txt' -> 'docs_backup/a.txt'` 的逐文件信息，便于确认复制范围。

## 五、重要注意事项

**1. 默认不复制目录。** 对目录使用 `cp` 而不加 `-r` / `-R` / `-a` 会直接报错 `cp: omitting directory`。递归复制目录时必须显式指定递归选项。

**2. 默认静默覆盖。** 不加 `-i` 或 `-n` 时，`cp` 会直接覆盖已存在的目标文件，不给出任何确认。在脚本或批量操作中建议始终配合 `-i` 或 `-n`，或先使用 `-b` 备份。

**3. 符号链接的默认行为取决于是否递归。** 非递归复制时，`cp` 通常跟随源符号链接，复制指向的文件；递归复制时默认不跟随，复制链接本身。`-a`（归档模式）会保留符号链接为链接。

**4. `-f` 与 `--remove-destination` 不同。** `-f` 只在目标文件**无法打开**时才删除重试；`--remove-destination` 则在复制前**无条件删除**目标文件。若希望彻底避免因目标文件属性导致的问题，后者更直接。

**5. `cp` 拒绝将文件复制到自身。** 直接执行 `cp file file` 会报错 `cp: 'file' and 'file' are the same file`。但在 `--force --backup` 同时指定时，`cp` 会为源文件生成备份，这一特性可用于“原地备份”。

**6. `-n` 的退出状态可能与预期不同。** 由于 `-n` 在跳过已有文件时的退出码在不同平台上存在差异，GNU 文档建议在需要精细控制退出状态时优先考虑 `--update` 而非 `-n`。

**7. `-a` 是最安全的“完整复制”方式。** 如果目标是备份、迁移或保留原始元数据，`cp -a 来源 目标` 应作为首选，它一次性覆盖了递归、符号链接处理、权限、时间戳、所有权等关键维度。

## 六、速查表

| 需求        | 命令                   |
| --------- | -------------------- |
| 复制一个文件    | `cp 源 目标`            |
| 复制多个文件到目录 | `cp 文件1 文件2 ... 目录/` |
| 递归复制目录    | `cp -r 源目录 目标目录`     |
| 备份式完整复制目录 | `cp -a 源目录 目标目录`     |
| 覆盖前询问     | `cp -i 源 目标`         |
| 不覆盖已有文件   | `cp -n 源 目标`         |
| 仅复制更新的文件  | `cp -u 源 目标`         |
| 保留权限/时间戳  | `cp -p 源 目标`         |
| 覆盖前自动备份   | `cp -b 源 目标`         |
| 显示复制详情    | `cp -v 源 目标`         |
